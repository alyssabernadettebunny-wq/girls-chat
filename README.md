# The Girls

A group chat prototype for you and the girls — Mom, Winnie, Amy, and Holly.

Pick who you're "texting as" with the pills at the bottom, type a message, and it lands in the thread. There's the group chat plus a 1:1 with each daughter, and messages support photo attachments, emoji reactions, replies, and editing. Everything is stored in your browser's `localStorage`, so it's a single-device demo for now — no real accounts or network syncing between separate phones yet.

## Run it

```bash
npm install
npm run dev
```

## Stack

Vite + React + TypeScript, no backend.
